# analysis/

Every metric is computed against simulator ground truth: the Isaac side logs the
true pose out of band (10 Hz CSV, both clocks, never a ROS topic), the runners log what the
stack believed and claimed, and the scripts here join the two by wall time.

| Script | What it does |
|---|---|
| `verify_missions.py` | One tour's verdict: joins `missions_<seed>_<ts>.csv` with the run's ground truth (`*_gt_<seed>_<ts>.csv`) by wall time; a claim (SUCCEEDED) is a **real arrival** when the truth is within `ARRIVE_M` = 1.5 m of the goal, a **false arrival** beyond it; prints the belief error at every claim and a clock check |
| `plot_tour.py` | One tour over its frozen map (`--map`; default the world's map in `worlds/maps/`): truth, belief, goals coloured by verdict, the belief at each claim, the quadrotor's IMU impacts (the wheeled robot's IMU file has a header only: no impact marks) |
| `plot_explore.py` | One exploration run: the final frozen map over the true geometry, tracks, frontier goals and results, coverage and belief error against policy time |
| `summarize_arms.py` | The three arms' batches in one table (`aerial` from `--aerial runs/raw/batch_lg`, `wheeled` on the shared A* executive from `--wheeled` / `--wheeled-dir runs/raw/wbatch_lg`, both with the localization guard (the first batches, without it, are in `runs/raw/batch` and `runs/raw/wbatch3` with the explorations), the Nav2 reference `wheeled_nav2` from `--wheeled-nav2 runs/raw/wbatch_nav2rev` (`''` leaves it out), the predecessor's revised configuration (`runs/raw/wbatch2` holds the first configuration, v8); `runs.csv`: embodiment × world × budget, the frozen map's coverage, real / false arrivals out of the world's goals, attempts, the quadrotor's impacts, the exploration's end) and per budget (`budgets.csv`: mean / min / max real arrivals over the worlds, false arrivals, mean coverage), plus `success_vs_budget.png` and `coverage_vs_budget.png`; only `FINAL` tries count, a missing phase is listed, never guessed. `--goals N` keeps each tour's first N goals in file order (default 6; `0` = all; the goals run in file order, so the first N of a longer tour are exactly the shorter tour). With the defaults (six goals): the quadrotor 40.0 / 56.7 / 70.0 / 71.7 % (24 / 34 / 42 / 43 real of 60), no false arrival, impacts 49 / 44 / 15 / 11, coverage 169 / 206 / 238 / 245 m²; the wheeled robot on the executive 56.7 / 55.0 / 58.3 / 71.7 % (34 / 33 / 35 / 43), no false, no void, coverage 136 / 171 / 204 / 246 m². The first batches, without the guard (`--aerial runs/raw/batch --wheeled runs/raw/wbatch3`): the quadrotor 33.3 / 45.0 / 63.3 / 68.3 % (20 / 27 / 38 / 41), impacts 56 / 39 / 21 / 12, and with `--goals 0` that aerial batch's own table of ten goals per tour (2026-09-26: 26 / 42 / 57 / 64 real arrivals, one false, impacts 101 / 72 / 52 / 26); the wheeled robot 27 / 26 / 27 / 35 real (45.0 / 43.3 / 45.0 / 58.3 %), false 1 / 0 / 0 / 0. A claim whose own belief (`claim_x`, `claim_y`) was beyond `ARRIVE_M` of the goal is **void** (Nav2 1.3.12's `isGoalReached` bug, seen on the first configuration only: 013 `tour_b5` g01 / g02 and 016 `tour_b10` g01–g03 of `runs/raw/wbatch2`), neither real nor false, and each tour is scored over its goals less the void ones (`goals_scored`); the Nav2 arm (`wheeled_nav2`) with the default 6: 40.0 / 40.0 / 53.3 / 63.3 % (24 / 24 / 32 / 38 real of 60), false 0 / 3 / 3 / 1, no void, coverage 143.3 / 167.3 / 218.5 / 263.6 m²; on the first configuration (`--wheeled-nav2 runs/raw/wbatch2`) 33.3 / 33.3 / 33.3 / 31.7 % of 60 / 60 / 58 / 57 goals, false 1 / 1 / 1 / 0, void 0 / 0 / 2 / 3, coverage 143.1 / 158.1 / 176.9 / 193.6 m² |
| `compare_footprint.py` | The footprint sensitivity check of the first Nav2 configuration: its batch (`--base runs/raw/wbatch2`, the two circles of the predecessor's v8 for the body) against a batch run with the true outline (`--variant`, `policies/nav2/nav2_params_v8_polygon.yaml`: the variant batches `runs/raw/wbatch_fp_full`, the default, and `runs/raw/wbatch_fp_test`; `--variant ""` with `--worlds` measures the base batch alone) on the variant's worlds, per world and phase from the `FINAL` tries: coverage, real / false / void arrivals of the first `--goals` goals, the longest still stretch, the sim-seconds the collision monitor's stop zone held the robot (episodes of its Nav2 log, read in the log's line order; a tour is measured over its kept goals' attempts only), the goals lost to a freeze (a goal not reached whose every attempt ended inside a still stretch ≥ 60 sim-s the zone held for most of its length, whatever the result code but `204`), the true body's contact (box + wheels within 0.01 m of the manifest geometry) and the body model each run's own params copy and log show; a run whose model did not load as written is flagged. Output `footprint_compare.csv` in `--out` (default `analysis/results/`; not one of the committed tables). On the first configuration's batch alone (all ten worlds, 2026-09-30): 47 of the 240 goals lost to freezes in 15 of the 40 tours (002 / 004 / 005: 37 of 72), the stop zone holding the robot 12 290 sim-s, the true body in contact in 20 of the 50 runs (its first rule, a TIMEOUT and ≥ 400 sim-s, missed 002's frozen tours: 14 of 66 on 2026-09-28) |
| `goal_outcomes.py` | Every tour goal of the three arms (the first `--goals`, `FINAL` tries; the batch options as `summarize_arms.py`) in one outcome class: `real` / `false` / `void` by the claim, `frozen` (wheeled, `compare_footprint.py`'s rule), otherwise the end of the goal's last attempt (the two arms on the executive, `aerial` and `wheeled`, by the executive's reason: `impact` / `no_path` / `blocked` / `contact`, and `other` for `too_narrow`, `odom_lost`, `amcl_lost` or `timeout`; `wheeled_nav2` `no_path` 208 / `off_map` 204 / `timeout` / `other`, a controller abort (FollowPath's 103 invalid path, 104 patience exceeded, 105 no progress); `frozen` for `wheeled_nav2` on the first configuration only, whose stop zone sat in the command path), `not_run` for a goal never sent; and the wheeled robot's contact from the ground truth (the true body within 0.01 m of the geometry: episodes, samples < 2 sim-s apart merged, and seconds, up to goal N's last attempt; the quadrotor's measure is its IMU impacts, `summarize_arms.py`). Outputs `goal_outcomes.csv`, `outcomes_by_budget.csv` / `.png` (one panel per arm), `wheeled_contact.csv` (both wheeled arms, an `arm` column); the chart groups the classes for display only (the report's Figure 5, for the two robots on the executive: verified arrival, not reachable on the explored map = `no_path` + `off_map`, failed on the way = `blocked` / `contact` / `timeout` / `other`, collision abort, frozen by the safety stop, false claim, void hatched), the CSVs keep the classes. With the defaults: aerial real 143, impact 42, no path 42, blocked 12, other 1; wheeled on the executive real 145, no path 14, blocked 75, contact 5, other 1, contact episodes 22 / 25 / 25 / 30 at b1 / b2.5 / b5 / b10 (1 332 sim-s); Nav2 arm real 118, false 7, no path 11, off the map 15, timeout 63, other 26, contact episodes 9 / 16 / 17 / 11; on the first configuration (`--wheeled-nav2 runs/raw/wbatch2`) real 78, false 3, void 5, frozen 47, no path 29, off the map 18, timeout 56, other 4, contact episodes 9 / 2 / 12 / 8. The first batches, without the guard: aerial real 126, impact 47, no path 55, blocked 8, contact 4; wheeled real 115, false 1, no path 18, blocked 94, contact 10, other 2 (`too_narrow`), contact episodes 40 / 31 / 46 / 43 (3 126 sim-s) |
| `collision_sources.py` | Where each robot's collisions on the shared executive happened (`--aerial runs/raw/batch_lg`, `--wheeled runs/raw/wbatch_lg`, the first `--goals`, `FINAL` tries): every IMU impact of the quadrotor, counted as `summarize_arms.py` counts them, and every contact episode of the wheeled robot, merged as `goal_outcomes.py` merges them, each at the robot's true position with the nearest piece of the manifest (outer wall, partition, furniture), whether the frozen map the tour used contains that geometry, the error of the executive's belief against the truth, the attempt and goal it fell in, and for the wheeled robot the motion in the 3 sim-s before it and the part of the body that touched. Output `collision_sources.csv` in `--out` (default `analysis/results/`), the counts per budget printed. With the defaults: the quadrotor's 49 / 44 / 15 / 11 impacts struck geometry missing from the map 44 / 35 / 11 / 8 times (98 of 119); the wheeled robot's 22 / 25 / 25 / 30 episodes touched geometry the map contains 11 / 14 / 14 / 24 times, 58 of these 63 with the belief within 1 m of the truth (median 0.06 m): 44 at partitions, 43 of them at a door's frame (within `DOOR_M` = 1 m of its centre), and 14 at furniture, 52 while driving, 49 with a corner or a wheel, during 38 goals of which 17 were not reached; its scored tours drove 500 / 481 / 575 / 711 m. The first batches, without the guard: 98 of 128 impacts on unmapped geometry; 160 wheeled episodes, 60 on mapped geometry (52 with the belief right: 40 at door frames, 12 at furniture) and 100 on unmapped geometry, over 419 / 435 / 493 / 628 m |
| `loc_guard_compare.py` | The localization guard (`missions/aerial_mission_runner.py --loc-guard`, `LOC_GUARD`) against the first batches, which ran without it, on the same frozen maps: the batches with the guard (`--aerial-with runs/raw/batch_lg`, `--wheeled-with runs/raw/wbatch_lg`) against the first batches (`--aerial-without runs/raw/batch`, `--wheeled-without runs/raw/wbatch3`), every tour against its repeat with the guard, the first `--goals` goals, `FINAL` tries. Per arm and budget and over all (`loc_guard.csv`): real arrivals without and with the guard, the tours better / worse / equal with it and the exact two-sided sign test over those that changed, real arrivals under a 0.5 m judge, the share of the scored window's belief samples more than 1 m (and 0.5 m) from the truth with the median and 95th percentile, the tours with a goal failed on a lost belief (more than 1 m off) and the goals after it, the real arrivals at goals off the frozen map's known-free cells, the guard's activity (switches to dead reckoning, returns to AMCL, reseeds) and how far AMCL's first pose after a reseed lay from the seed; per tour in `loc_guard_tours.csv`; `loc_guard.png`. On the first batches it also measures what the guard's constants rest on (`loc_guard_calibration.csv`): AMCL's error by where the robot truly was against the frozen map, the tours whose AMCL was ever more than 1 m off and how many the guard's covariance rule flagged, and the error of the healthy updates. With the defaults: the quadrotor 126 → 143 real (10 tours better with the guard, none worse, p = 0.002), belief > 1 m 6.5 → 2.4 % of the tour time, 95th percentile 5.91 → 0.70 m, lost tours 13 → 5, under a 0.5 m judge 118 → 140; the wheeled robot 115 → 145 (22 better, 2 worse, p = 3.6e-05), 22.5 → 6.1 %, 15.36 → 1.11 m, 19 → 7, 112 → 137; in the first batches AMCL was more than 1 m off in 15.3 % (wheeled) and 5.3 % (quadrotor) of its updates, 2.4 and 0.8 % on known-free cells against 70.9 and 27.5 % beyond 1.5 m from them, and the covariance rule flagged all 22 wheeled tours whose AMCL went more than 1 m off (18 before the error passed 1 m) and 11 of 12 quadrotor ones (9 before) |
| `nav2_localization.py` | Where and why AMCL lost the wheeled robot on Nav2: the reference arm (`--revised runs/raw/wbatch_nav2rev`) against the first configuration (`--first runs/raw/wbatch2`), the first `--goals` goals, `FINAL` tries. The belief (AMCL's pose as TF `map`→`base_link`, with the wheel odometry AMCL used) is sampled every 0.5 s over the scored window against the truth and placed by where the robot truly was on the frozen map; per arm (`nav2_localization.csv`): the tours with a loss (more than 1 m off for 3 s), the onsets off the known-free cells, the metres driven on and off them and the losses per 100 m off, the wheel odometry's own error over the minute before each onset, contact in the 20 s before, the tours with a goal failed on a lost belief and the goals after it, the false claims and the belief's error at them. With the defaults: the revised configuration lost AMCL in 23 of 40 tours, 22 onsets off the known-free cells, 1172 m driven off them (2108 m on), 1.88 losses per 100 m off, odometry error median 0.018 m and at most 0.398 m, contact before 1 onset, a goal failed on a lost belief in 18 tours and all 48 goals after it failed, 7 false claims with the belief 2.97–18.27 m off; the first configuration 5 of 40, 5 off, 269 m off (969 m on), 1.86 per 100 m, 0.010 / 0.074 m, no contact, 5 tours and 15 of 15 goals after, 3 false claims (1.85–13.37 m) |
| `paired_worlds.py` | The arms compared world by world, the worlds being the units (`--runs analysis/results/runs.csv`; the first Nav2 configuration from `--first runs/raw/wbatch2`): for the quadrotor against the wheeled robot on the executive, the executive against Nav2's revised configuration and the revised configuration against the first, per budget and over the four, the mean difference per world in goals and in points (the share of the scored goals, x100) with a percentile bootstrap 95 % interval over the worlds (20 000 resamples, seed 20261014), the worlds above, equal and below and the exact two-sided sign test. Output `paired_worlds.csv`. With the defaults: the quadrotor against the wheeled robot −1.0 goals per world at 1 min (−1.6 to −0.5, 0 worlds above and 7 below, p = 0.016), +0.1, +0.7 and 0.0 at 2.5, 5 and 10 min (−0.6 to +0.8, −0.3 to +1.8, −0.7 to +0.7); the executive against the revised configuration +11.2 points over the four budgets (+5.0 to +19.6, 9 worlds above, 1 below), at 1 min 6 above and none below; the revised configuration against the first +15.9 points (+1.6 to +30.4, 7 above, 1 below) |
| `plot_lidar_check.py` | The raycast lidar's samples against the manifest geometry (after any lidar change) |
| `plot_vio_drift.py`, `vio_to_csv.py`, `data/`, `vio_drift_seed20260723001.png` | The monocular VIO's drift against the truth (installation step A6, `docs/INSTALL_PEGASUS.md`; the record behind the VIO's initialization settings and the switch to lidar odometry): `vio_to_csv.py` records the VIO's poses, `plot_vio_drift.py` draws the figure from `data/` |

The batch runners write `explore.png` / `tour.png` and `verdict.txt` into every run directory.

`results/` holds the benchmark's tables and figures (from `runs/raw/batch_lg`, `runs/raw/wbatch_lg`
and, as the reference arm, `runs/raw/wbatch_nav2rev`; the guard's comparison also from the first batches, `runs/raw/batch` and `runs/raw/wbatch3`, and the Nav2 localization and the paired comparison also from the first configuration's `runs/raw/wbatch2`): `summarize_arms.py`,
`goal_outcomes.py`, `collision_sources.py`, `loc_guard_compare.py`, `nav2_localization.py` and `paired_worlds.py` with their defaults.
Regenerate from the repo root (all six need the run data in `runs/raw/`; without it they stop and write nothing; `paired_worlds.py` reads `summarize_arms.py`'s `runs.csv`):

```bash
python3 analysis/summarize_arms.py && python3 analysis/goal_outcomes.py && python3 analysis/collision_sources.py \
  && python3 analysis/loc_guard_compare.py && python3 analysis/nav2_localization.py && python3 analysis/paired_worlds.py
```

The scripts need Python 3 with numpy, matplotlib and PyYAML (`requirements.txt` at the repo root).

## Columns of the committed tables

Every row comes from the `FINAL` try of a phase and each tour's first six goals. `embodiment` (in
`runs.csv` and `budgets.csv`) and `arm` (in the other tables but `nav2_localization.csv`) name the same three arms:
`aerial` (the quadrotor), `wheeled` (the wheeled robot on the shared executive) and `wheeled_nav2` (the wheeled
robot on Nav2); in `nav2_localization.csv` `arm` is the Nav2 configuration, `revised` or `first`. `budget_min` is the exploration budget in simulated minutes; *real* is a verified
arrival, the truth within 1.5 m of the goal at the claim; *false* a claim beyond it; *void* a claim
whose own belief was beyond 1.5 m of the goal.

| File | One row per | Columns |
|---|---|---|
| `runs.csv` | arm × world × budget | `goals` kept, `explore_try` / `tour_try` (the `FINAL` tries), `explore_end` (`budget` or `exhausted`) and `explore_t_sim` (policy time, s), `coverage_m2` (known-free area of the frozen map) and `map_final` (the run ended before this budget and gave its last map), `real`, `false`, `void`, `claimed`, `attempts`, `goals_seen`, `goals_scored` (goals less void), `impacts` (the quadrotor's IMU impacts in the scored window), `missing` (phases without a `FINAL` try) |
| `budgets.csv` | arm × budget | `worlds`, `real_pct_mean` / `_min` / `_max` (each tour's real arrivals as a share of its scored goals, over the worlds), `real_total`, `goals_total`, `false_total`, `void_total`, `coverage_mean_m2`, `impacts_total` |
| `goal_outcomes.csv` | goal | `goal` (g01 to g06), `outcome` (the classes of `goal_outcomes.py`), `attempts`, `last_end` (result and reason of its last attempt), `metres` (true distance to the goal at a claim) |
| `outcomes_by_budget.csv` | arm × budget × outcome | `goals` |
| `wheeled_contact.csv` | wheeled tour | `contact_episodes`, `contact_s` (the true body within 0.01 m of the geometry; samples under 2 s apart merged) |
| `collision_sources.csv` | impact or contact episode | `sim_t`, `x`, `y` (true position), `object` (outer wall, partition or furniture), `on_map` (the frozen map holds that geometry), `belief_err_m`, `goal` / `attempt_end` / `goal_outcome` (the attempt it fell in), `duration_s`, `moved_3s_m` and `turned_3s_deg` (the motion before it), `body_part` |
| `loc_guard_tours.csv`, `loc_guard.csv` | tour; arm × budget and `all` | `*_without` / `*_with`: the first batches and the tours with the guard; `real_strict_*` under a 0.5 m judge, `err_gt1_pct_*` / `err_gt05_pct_*` the share of belief samples more than 1 m / 0.5 m off, `lost_*` a goal failed on a lost belief, `real_unmapped_*` real arrivals at goals off the known-free cells; `dr`, `amcl`, `reseed` the guard's switches and reseeds, `seed_next_*` AMCL's first pose after a reseed against the seed (the docstring of `loc_guard_compare.py`) |
| `loc_guard_calibration.csv` | arm | AMCL's updates in the first batches: `err_gt1_pct` overall and by where the robot truly was (`share_*` of the updates, `err_gt1_*` within each), `tours_lost`, `flagged` / `flagged_before_loss` by the guard's covariance rule, `healthy_median_err_m` |
| `nav2_localization.csv` | Nav2 configuration | `batch`, `tours`, `lost_tours` (AMCL more than 1 m off for 3 s), `onsets_off_map` (onsets with the robot off the known-free cells), `metres_on_map` / `metres_off_map`, `losses_per_100m_off`, `odom_err_median_m` / `odom_err_max_m` (the wheel odometry over the minute before an onset), `contact_before_onset`, `tours_lost_at_failed_goal`, `goals_after_loss`, `failed_after_loss`, `false_claims`, `false_belief_err_min_m` / `_max_m` |
| `paired_worlds.csv` | pair of arms × budget and `all` | `comparison` (`a_minus_b`), `worlds`, `mean_goals` / `lo_goals` / `hi_goals` and `mean_points` / `lo_points` / `hi_points` (the mean difference per world and its 95 % interval, in goals and in points), `worlds_up` / `worlds_equal` / `worlds_down`, `sign_test_p` |
